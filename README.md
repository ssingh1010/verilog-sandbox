# verilog-sandbox

Small Verilog practice problems with matching test benches.

## Included examples

- `src/full_adder.v` with `tb/full_adder_tb.v`
- `src/priority_encoder_4to2.v` with `tb/priority_encoder_4to2_tb.v`

## Run the simulations

```bash
make test
```

You can also run each example independently:

```bash
make full_adder
make priority_encoder_4to2
```
